# Wordline Animation — Visual Identity

## Direction

Wordline Animation is a **fun, entertaining animation channel first**.

The identity must not feel sophisticated, luxurious, editorial, academic, or "premium corporate." The old elegant Worldline Lab language is retired for this channel.

### Retired
- Playfair Display
- serif headline systems
- dark green / sage-led branding
- sophisticated editorial cards
- constant scientific HUDs
- elegant magazine-style chapter graphics
- prestige-documentary visual language

### Keep
- cinematic low-poly animation
- expressive characters
- strong camera work
- readable silhouettes
- physical comedy
- visual storytelling
- absurd escalation
- recurring jokes and callbacks
- polished lighting and sound

## Core palette

The channel base shifts to a playful dark-blue family:

| Role | Color |
| --- | --- |
| Deep Navy | #0B1220 |
| Wordline Blue | #162A46 |
| Bright Sky | #4DA3FF |
| Fun Yellow | #FFD166 |
| Chaos Coral | #FF6B6B |
| Off White | #F5F7FB |

Dark blue is the anchor, not a permanent wash over every animated world. Story environments can use whatever colors serve the scene.

## Typography

No serif display fonts.

Official family: **Rubik**.

- **Headline / thumbnail:** Rubik ExtraBold / Black
- **Supporting text:** Rubik Medium
- **Body / credits:** Rubik Regular

Use one family by default so the channel stays visually consistent. Typography should feel bold, readable, energetic, and slightly playful. Never elegant for elegance's sake.

## Where branding should live

Branding should mostly appear in:
- YouTube banner and avatar
- thumbnails
- occasional opening/closing logo
- channel cards
- credits
- social packaging

The animation itself should not be forced into a permanent graphic template.

## In-video graphics

Use graphics only when the story genuinely needs them:
- a clock
- a phone screen
- a sign
- a map
- a simple label
- a countdown
- diegetic interfaces

Avoid persistent HUDs, decorative data panels, chapter slates, or "scientific" overlays unless the joke or story specifically depends on them.

## YouTube-first thumbnail language

- one absurd visual idea per thumbnail
- readable at phone size
- character emotion or scale contrast whenever possible
- dark-blue branding may frame or support the composition, but should not flatten the scene
- text optional; when used, usually 1–4 words
- large bold sans only
- prefer bright blue / yellow / coral accents over elegant muted palettes

## Channel personality

The identity should feel like:

**cinematic low-poly worlds + funny characters + weird consequences + strong sound + unexpected endings**

A viewer should think:

> "This looks like a polished animated story that might go completely off the rails."

Not:

> "This looks like a formal science explainer."
