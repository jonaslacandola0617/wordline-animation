# WORDLINE EPISODE 001 — RANDOM DOORS

**What If Every Door Took You Somewhere Random?**

The story is locked. Production treats the model as the animation department, not the writer.

## Architecture
- 11 independent deterministic Three.js scenes
- scene-by-scene frame rendering
- actual Wordline human, City Bus and interior assets
- Wordline Audio Pack 01 first for Foley/SFX
- neural dialogue generation attempted per scene and logged
- original deterministic procedural underscore
- 1080p QA render first, then 4K delivery upscale for review
- native 4K scene mastering follows visual approval rather than spending hours mastering bad frames

## Actual asset selections
A = HUMAN_02, B = HUMAN_03, C = HUMAN_04, D = HUMAN_08.
Background = HUMAN_01 / HUMAN_05.
Bus = 03A LAND_01.
Interiors = 03B INTERIOR_02, 04, 05, 06, 08, 11, 12.

Architecture, ordinary doors, cake, donut, simple laundromat equipment and tsunami geometry are procedural support because no matching supplied functional asset was found.
